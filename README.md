# Habr-Jev-Agent

Автономный редактор технологических новостей: Laya (System One) классифицирует вход,
Gemma через собственный Python harness готовит материал, приложение проверяет его
и публикует в Ghost. Реализация FastAPI, worker и инструкция запуска — в [app/](app/README.md).

Репозиторий содержит независимые Compose-проекты:

- `laya/` — классификатор; исходники подключены Git submodule.
- `llm/` — llama.cpp с Gemma и поддержкой tool calling.
- `blog/` — Ghost с MySQL.
- `app/` — API и последовательный worker на Python 3.12 с общей SQLite.

Для моделей и приложения используется внешняя Docker-сеть `agent-net`.
Секреты, базы и веса исключены из Git. Для разработки приложение подключается к
защищённым HTTPS-прокси; на сервере адреса заменяются через окружение.
